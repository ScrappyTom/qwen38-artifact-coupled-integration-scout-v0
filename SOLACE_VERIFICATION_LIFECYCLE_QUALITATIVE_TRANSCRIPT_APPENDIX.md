## Cross-arm qualitative synthesis

### What information changed behavior

The current candidate-bound check dominated both arms' immediate demand. Both
selected exactly the same source pairs in exactly the same order. The register
did not eliminate those reads.

The register became behaviorally distinguishable only after BASTION/CIPHER were
externalized. A1 still made a broad repair spanning those sources and exact
DELTA/INDIGO. That is consistent with semantic residue extending the usable
meaning of externalized sources.

### How the artifact became cumulative state

A0 never reopened BASTION, CIPHER, DELTA, or INDIGO. Once their facts entered the
decision, later calls operated on the exact artifact and check findings. This is
direct evidence that exact task work can replace some raw evidence residency
during repair.

A1 did the same conversion in one larger step. The difference was not whether
the artifact could carry meaning; it was the breadth, fidelity, and capacity cost
of the supporting state used to produce that step.

### Why neither system completed

The common terminal failure was not insufficient source access. It was a
lifecycle mismatch:

```text
current artifact
+ stale and current check records
+ patch effects
+ actor/action chronology
+ receipts
+ (A1 only) frozen register
        -> pending effect or next decision cannot fit
```

First-fit can demote old exact source/check bodies, but it cannot fold the
remaining wrappers and causal path into a bounded current verification state.

### What the checker taught and missed

The checker successfully focused work on real omissions and tracked candidate
currency. It also imposed avoidable surface-form repair and missed three material
relationship errors across the final candidates. Its next role should be a
candidate-bound expected/observed contract with explicit relationship semantics,
not a declaration of readiness.
