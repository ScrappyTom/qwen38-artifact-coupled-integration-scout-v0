# Clean whole-lifecycle governance

Date: 2026-08-30

This subproject creates a new prospective Trellis trajectory. It may not import
E103 candidate bytes, event state, checks, or inferred semantic progress.

The host owns exact custody, delivery, token accounting, first-fit relief,
candidate/effect/check bindings, section-boundary admission, checkpointing,
E97 applied-effect turnover, and E104 delivered-check turnover. It may not
select semantic facts, repair candidate content, infer understanding, or grant
readiness.

The model owns evidence requests, semantic maintenance output, construction,
verification requests, repairs, and closure proposals. Maintenance is
non-authoritative, charged, fallible, and demoted mechanically when the actor
enters verification.

Every live tranche stops after at most twelve completed actor calls. Review is
qualitative as well as mechanical. Continuation is never automatic, and any
policy change starts a new experiment.

No provider call is authorized by this subproject's offline qualification.
