# Project routing reset

Date: 2026-08-27

Status: active routing rule; no GPU operation authorized by this document

## Two separate lanes

This repository is an experimental system-interaction laboratory. It is not
the default Franken Agent product host.

The product incumbent is the donor-preserving writable integration at
`exact-world-agent-substrate` commit
`5b68b0d545bb4c3939ff5a53f9335168491e09ce`. Qwen owns its native controller,
prompts, model-facing tools, edit/check loop, and stopping behavior. Exact-world
sits below that boundary as candidate, validator, adoption, transport,
recovery, and replay authority.

Keystone, Orchard, Solace, and the other studies in this repository remain the
research lane. Their task worlds, semantic scaffolds, projections, activation
rules, and action protocols do not become product defaults merely because an
offline preflight or matched experiment passes.

## Promotion rule

A research mechanism may enter the donor-preserving product lane only when all
of the following are true:

1. a normal donor-host task demonstrates a concrete missing behavior;
2. the proposed mechanism is narrower than replacing the donor controller;
3. a matched donor-preserving integration fixes the demonstrated failure;
4. the model-facing donor workflow remains unchanged wherever possible;
5. artifact correctness, truthful closure, replay, and economics pass on a new
   task that did not shape the mechanism.

No atlas, semantic scaffold, causal frame, obligation ledger, or custom action
protocol is promoted by the Keystone experiment itself.

## E79 disposition

The sealed Keystone pressure screen is retained as valid negative evidence:

* nine actor calls;
* 102,009 serialized tokens;
* eight delivered sources and eight domains;
* CYBER acquired but not delivered across another actor boundary;
* candidate unchanged from its ten-word seed;
* no construction, check, rejected repair, or treatment-dependent decision.

The run measured a mismatch between a count-based pressure gate and the live
trajectory. It did not test bounded causal continuity.

## Only eligible Keystone continuation

There will be no replacement ten-source screen and no lowered count threshold.
The sealed E79 state may be used as an exact common prefix for one conditional
continuation:

```text
sealed E79 state
→ common positive-savings first-fit relief
→ deliver the already acquired CYBER result
→ ordinary actor-selected construction and verification
→ current candidate-bound check
→ rejected repair while candidate remains unchanged
→ later exact observation acquired while candidate remains unchanged
→ fork before the next actor decision, which delivers that observation
```

The fork compares only:

* `V0_CURRENT_ONLY`: the bounded current projection omits the unresolved
  rejection and recurrence;
* `V1_BOUNDED_CAUSAL_CONTINUITY`: the same projection retains the exact
  unresolved rejection and recurrence until candidate change.

If the exact trigger never occurs, Keystone closes as non-diagnostic. If V1
does not improve alternative repair, effect uptake, current recheck, readiness,
or truthful closure, the bounded-causal route closes rather than creating
another task world or activation screen.

## Experimental-economy rule

Every future GPU experiment must report `activation_tax`:

```text
model calls and serialized tokens consumed before
the first treatment-dependent model decision
```

A standalone GPU activation run is prohibited unless activation behavior is
itself the scientific question. Otherwise, the same prospective authorization
must cover the common continuation, conditional fork, and both bounded arms.

Product qualification and moderate real-repository writable work proceed
independently. The research lane may not block or redefine that product gate.
