## System question

Under authentic evidence pressure, does a complete bounded system with a
temporary, requirement-coupled, provenance-anchored semantic scaffold convert
evidence into verified cumulative work more reliably than the same viable
system using exact task-native work alone?

This is an interaction study, not a carrier qualification. Both configurations
receive exact custody, deterministic first-fit pressure relief, exact reopen,
the same task-native evidence matrix, the same incremental section actions, the
same candidate/effect/check bindings, the same verification transition, and
the same repair/recheck/closure surface.

- `A0_MATRIX_AND_DECISION`: exact evidence-to-requirement matrix plus exact
  incremental decision.
- `A1_SCAFFOLD_MATRIX_DECISION`: the same complete system plus a temporary
  anchored scaffold generated in bounded batches from newly externalized exact
  source results.

The A1 scaffold is a charged, fallible operation. Claims are admitted
independently. Invalid or unaffordable claims are discarded without repairing
model output; prior accepted state remains. The scaffold is removed when the
actor enters verification. Its intended role is construction scaffolding, not
permanent memory or readiness control.

## Fresh task and interaction geometry

Trellis is a synthetic urban heat-continuity decision with twelve interacting
sources spanning authority, heat triggers, power, water, clinical surge,
cooling-center accessibility, transit, communications, logistics, staffing,
candidate lineage, and independent review. It is independently evaluated for
cross-source relations, units, gates, currentness, artifact structure, repair,
and closure readiness.

The common action surface permits one or two exact ranges per decision, exact
reopen, exact matrix replacement, incremental decision sections, bounded
patches, an actor-selected verification transition, current checking, bound
section repair, recheck, and submission proposal.

`TRELLIS_STAGE0_RESULT.json` records zero model calls and establishes:

1. exact custody of twelve fresh sources and the initial candidate;
2. a prospective pressure event after five two-source batches and ten delivered

5. a real candidate-bound defect;
6. actor-visible targeted repair transport;
7. passing current recheck and submission mechanics; and
8. adequate lifecycle affordances for both complete configurations.

The pressure projection is a qualification argument, not live behavioral
evidence. The next eligible operation is the separately authorized,

until the exact live handoff is independently audited.

## Interpretation limits

A measured A1 advantage would support the complete scaffold-plus-artifact
configuration in Trellis; it would not prove that the scaffold alone caused
the outcome. An A0 advantage would support demoting semantic scaffolding in
this lifecycle. Either arm merely surviving longer is not useful completion.
Primary interpretation requires artifact quality, current effect uptake,
verification/repair, correct closure, and independently bound readiness.
