# Capability-terrain reconnaissance v0: program disposition

Date: 2026-08-23

Status: measured breadth tranche complete; result incorporated into discovery routing

## Answer first

The first breadth tranche did not find a context-capacity failure or a correct
end-to-end completion. It found a different and more immediate systems
boundary:

> At low context occupancy, the actor could sometimes integrate evidence,
> construct a large artifact, absorb its effect, and use a current check, but
> legal action expression and correct readiness discrimination were unreliable.

Across 39 actor calls, 19 responses were rejected before an action reached the
environment. D2 and D5 nevertheless completed substantial construction paths,
then submitted strong-partial artifacts after narrower visible checks passed.
D6 received D2's exact current state without its construction chronology and
repeated the same premature-closure disposition. No cell achieved independently
correct useful completion.

This result supplies a low-pressure reference regime. It does not answer the
program's intended interaction question. Context pressure, semantic
persistence, incremental work, and matched lifecycle alternatives never became
active together, so the tranche cannot establish how those functions alter one
another. Its valid contribution is to identify boundaries that a later
interaction study must keep inside the same closed loop.

## What the tranche teaches about the low-pressure regime

### 1. Useful operation is conjunctive

The observed economics are better described as:

```text
accessible information
x formed relation
x intended operation
x legal expression
x admitted effect
x discriminating feedback
x correct readiness decision
= useful completion
```

Ample context or successful acquisition cannot compensate for a zero at a later
boundary. D3 and D4 spent prompt-heavy calls repeatedly expressing tiny invalid
actions. D2 and D5 crossed expression, construction, and effect uptake, but lost
one governing requirement apiece and then trusted incomplete verification.

### 2. Action transport is part of the information economy

The model-facing protocol determines whether an intended operation can become
world state. A rejected 20-token action can consume the same scarce actor-call
slot as a substantive edit. This makes expression/admission a first-class
throughput boundary, not merely cosmetic output formatting.

The result does not show that JSON fencing caused the D2 or D5 semantic defects,
nor that silently repairing malformed actions would be safe. It does show that
an observation instrument must qualify its transport well enough to expose the
capability it claims to study.

### 3. Broad integration and exact construction are present but incomplete

D2 and D5 are important positive evidence. Under the same profile and action
surface, the actor acquired multiple exact objects, generated coherent large
replacements, received the mutation effects, invoked current checks, and
closed. The model therefore did not fail uniformly at discovery, integration,
construction, or effect uptake.

Both artifacts nevertheless omitted a material task relation. D2 lost the
complete-case/no-imputation qualification from Discussion. D5 failed to reject
a disabled service required by the dependency closure. Represented or available
requirements did not all constrain the artifact.

### 4. Verification and readiness are a coupled high-risk boundary

Both changed artifacts passed their visible checks while failing broader frozen
evaluation. The actor then submitted them. D6 repeated D2's closure disposition
from an exact fresh packet without rereading, rechecking, or repairing.

The supported claim is not that exact reentry is harmful in general. It is that
exact current-state reconstruction can preserve an action disposition—including
an incorrect one—without creating independent readiness judgment. Candidate
state, check coverage, evaluator scope, and closure policy must remain distinct.

### 5. The intended context interaction was not exposed

No prompt approached pressure. Therefore the tranche supplies no evidence about
how eviction, semantic persistence, incremental work, or resumption would have
interacted with the measured action and readiness behavior. It is reasonable to
say that context capacity did not cause these literal cells; it is not
reasonable to use them to rank context against other constraints or to infer a
general architecture.

## Capability-terrain update

The tranche changes the evidence map in four useful ways:

1. **Expression/admission now recurs within Qwen3.8 breadth as well as the
   sister code program.** Its exact cause is interface- and state-dependent,
   but it is broad enough to treat as a consequential system boundary.
2. **Relation-to-action loss recurred in two independent task lineages within
   the tranche.** One prose artifact and one code artifact were substantial but
   each omitted a governing qualification or rule.
3. **Readiness failure recurred across independent artifacts.** Visible checks
   were current but incomplete; submission did not establish quality.
4. **Exact reentry preserved closure orientation but not correctness.** D6 is a
   same-lineage descriptive result, not an independent replication or causal
   chronology ablation.

D1, D3, and D4 do not establish inability in their downstream task functions.
The action interface prevented those functions from becoming observable within
the frozen horizons. This distinction is central to future probe design.

## Program routing after the tranche

The program remains in structured exploration, but the next unit is a whole
system configuration rather than three separately routed questions. Under an
authentic shared pressure state, the first candidate scout crosses:

- source-bound semantic residue after exact-body demotion; and
- incremental exact task work that can survive source turnover.

Every viable configuration retains common exact custody, first-fit pressure
relief, reopen, action transport, effects, feedback, and external readiness
evaluation. The study follows the resulting demand and artifact trajectory
through a common bounded resumption event. It asks whether the two persistence
channels substitute, complement, interfere, or merely move the terminal
failure.

Action-transport qualification is an apparatus gate because E37's interface
censored three cells. It is not promoted into a separate research branch.
Likewise, relation binding, feedback, repair, and readiness are downstream
joint outcomes of each configuration, not independent experiments to be run in
sequence.

The governing contract is `SYSTEM_INTERACTION_EXPLORATION.md`. A new measured
wave should not automatically repair and rerun D1, D3, or D4, tune the same JSON
prompt, or repeat D6 with different wording.
