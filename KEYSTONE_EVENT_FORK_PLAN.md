accessible-world size, and first context pressure are not activation units.

## Exact fork trigger

The fork is armed only after one live trace contains this ordered sequence:

1. an admitted `begin_verification` phase effect on a candidate different from
   the E79 seed;
2. a current check observation bound to that exact candidate;
3. a mutation action rejected with the candidate unchanged;
4. a later exact source or reopen observation is acquired with that candidate
   still unchanged; and
5. no intervening candidate mutation.

The first treatment-dependent decision is the next actor decision after item
4. That decision's prompt delivers the pending exact observation in both arms.
`reactive_runtime.causal_activation.detect_causal_fork_activation` is the
single mechanical detector. It does not inspect source semantics.
