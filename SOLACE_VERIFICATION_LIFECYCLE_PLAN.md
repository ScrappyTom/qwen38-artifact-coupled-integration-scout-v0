Status: offline Stage 0 implemented; GPU execution not authorized.

## Question

After provenance-bound semantic residue has helped produce substantial exact task work, does retaining that residue improve verification and repair, or has the exact artifact absorbed enough useful meaning that the residue is now redundant or harmful?

This is a lifecycle interaction ablation, not an attempt to explain the earlier W0/L1 construction divergence.

## Repair transport

The new `patch_decision` action applies 1–24 actor-selected exact replacements. Every old anchor must occur exactly once. Per-action old-anchor and replacement-byte limits keep the action bounded.

This is intentionally different from a complete decision replacement. The provider-free fixture repairs all five frozen defects using eleven localized edits, fits inside the 4,096-token response channel, makes the prior check stale, passes a new candidate-bound check, and reaches the submission surface.

The fixture proves apparatus reachability only. It does not prescribe or repair a live model response.

## Budgets

The clean lifecycle is four decisions:

1. current check;
2. bounded repair;
3. current recheck;
4. submission proposal.

Each cell receives twelve actor calls: four for the clean path, six additional bounded repair or exact-recovery decisions, and two expression-failure decisions. There are no retries and no maintenance calls. The two-cell maximum is twenty-four provider calls.

## Interpretation

Possible results:

* A1 outperforms A0: the semantic scaffold retains marginal value during verification.
* A0 matches or outperforms A1: the artifact has likely absorbed enough meaning, and retaining the scaffold imposes cost or distraction.
* both repair and close correctly: fresh exact current-state verification is sufficient; register value is marginal.
* both fail before a current check: verification action geometry remains the bottleneck.
* either submits with a failing or stale check: readiness discrimination fails.

No result from this scout isolates why L1 began constructing earlier than W0. That requires fresh-world transfer of the complete acquisition-to-construction interaction.
