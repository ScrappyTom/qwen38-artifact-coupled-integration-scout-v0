## Research question

Can a complete bounded verification lifecycle preserve both current state and
the small amount of exact unresolved causality needed to convert feedback into
non-repeating repair and correct closure?

The treatment is not “add a memory field.” The unit is the whole trajectory:

```text
evidence ingress
→ semantic scaffold × exact incremental artifact
→ actor-selected verification
→ bounded current check × exact causal continuity
→ uniquely bound repair
→ effect uptake
→ current recheck
→ independently correct readiness and closure
```

## Compared viable systems

Both configurations share exact custody, first-fit relief, source access,
temporary anchored semantic scaffolding, exact incremental artifact work,
actor-selected verification, the new uniquely bound section repair, current
candidate/check projection, resource budgets, and external evaluation.

### V0 — current verification without persistent causal slots

V0 replaces candidate/check/update state as events arrive. A later observation
may displace a prior rejection from the compact current projection. Exact full
history remains externally reopenable.

### V1 — current verification with bounded exact causal continuity

V1 uses the same complete system and additionally projects:

* latest attempted action and outcome;
* latest unresolved rejected mutation until candidate change;
* exact repeated-action count inside the current candidate epoch; and
* exact history handle.

The host does not recommend a next action, infer intent, or authorize closure.
Recurrence is telemetry and actor-visible state, not an automatic trigger.

but economically unearned representation.

non-diagnostic. If both repair but close incorrectly, readiness remains the
dominant boundary.

repair or submission.
