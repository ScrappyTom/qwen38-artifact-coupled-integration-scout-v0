# Solace fault-tolerant anchored-provenance interaction Stage 0

Date: 2026-08-26

Status: offline Stage 0 implemented; no provider or GPU call authorized

## Whole-system question

Under authentic result-delivery pressure, does a fallible, provenance-bound
semantic residue improve cumulative exact task work, relationship fidelity,
verification, repair, and closure over direct exact work alone?

This is not another expression gate. The research unit is the full operating
trajectory after a common pressure fork.

## Fresh task and world

Solace is a new regional drinking-water recovery task with fourteen exact,
versioned sources across authority, hydraulics, laboratory sampling, pumping,
power, treatment, source water, security, observability, environmental duties,
logistics, communications, change control, and independent readiness. Twelve
hidden requirement groups form a many-to-many evidence graph.

The task requires an exact evidence matrix and an incrementally constructible
1,500–2,100-word recovery decision. This preserves the task artifact as one
channel of external cognition while testing a second, source-bound semantic
channel.

## Responsibility allocation

The model supplies:

- source slot and exact version;
- assertion mode and relationship referents;
- one semantic statement; and
- one exact, unique, single-line anchor substring selected from a delivered
  source result.

The host supplies mechanically:

- exact anchor bytes and byte offsets;
- the complete containing source line as a context span;
- anchor and context hashes;
- source/version/result bindings;
- currentness and exact reopen custody.

Locality constrains mutation authority, not which objects a grounded
relationship may name.

## Fault-tolerant admission

A syntactically valid, in-budget envelope is parsed into independent claim
records. Each record is validated separately. Duplicate IDs and per-source
budget excess reject the affected records atomically. Valid records merge;
invalid records are preserved in audit custody but discarded. If zero records
are valid, the prior register remains byte-identical and the ordinary actor
continues. There is no repair, retry, silent truncation, or semantic host fix.

A malformed or over-budget global envelope is wholly rejected. Partial
admission does not imply source completeness: the rendered register explicitly
states that omission is not evidence of coverage.

## Offline geometry

The exact source corpus is 51,549 bytes and 18,282 tokenizer tokens. The base
actor prompt is 2,782 tokens. A fixed, permitted full-pair path crosses the
20,992-token prompt allowance on its sixth result at 21,175 tokens. Replacing
only `RESULT-001` restores feasibility at 18,559 tokens. This is a prospective
opportunity, not evidence that the live actor will take the same path.

Every frozen maintenance fixture fits the 25,088-token model context with its
1,800-token completion allowance. Provider-free fixtures prove both arms can
execute exact ingress, construction, defect-bearing check, repair, stale-check
recognition, current recheck, submission proposal, and identical final
candidate state. L1 additionally materializes and merges grounded factual and
relational records. A mixed-validity fixture admits one record and rejects one;
a zero-valid fixture leaves the register unchanged.

These qualify apparatus reachability, not model expression or utility.

## Live sequence

1. Run one treatment-free ordinary pressure screen on the fresh task.
2. If an eligible authentic boundary occurs, freeze the exact common fork.
3. Build the two-arm continuation from that fork. Do not insert a standalone
   expression qualification.
4. In L1, maintenance yield and failure are measured inside the trajectory.
5. Continue both arms through induced reads, exact task work, effect uptake,
   checks, repair, recheck, readiness, and closure or resource exhaustion.

The pressure screen cannot authorize semantic maintenance or measured
continuation. Each later operation requires its own frozen commit and explicit
authorization.

## Claim limits

- E66 remains a valid negative for complete-line copying; this route does not
  retroactively regrade or repair it.
- Exact anchor occurrence and context custody do not establish semantic truth.
- Partial admission can preserve bad semantics as well as good semantics;
  final artifact evaluation remains mandatory.
- A positive L1 result supports the complete configuration, not a universal
  provenance format.
- A negative L1 result does not isolate whether production, admission,
  residency, induced demand, or artifact uptake dominated without trajectory
  analysis.
